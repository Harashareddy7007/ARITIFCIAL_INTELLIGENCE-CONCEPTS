## 📋 Prerequisites

Install the required libraries before running the notebooks:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn nltk jupyter
```

---

## 🚀 How to Run

1. Clone this repository

```bash
git clone https://github.com/Harashareddy7007/ARITIFICIAL_INTELLIGENCE-CONCEPTS.git
```

2. Navigate to the project folder

```bash
cd ARITIFICIAL_INTELLIGENCE-CONCEPTS
```

3. Open Jupyter Notebook

```bash
jupyter notebook
```

4. Open any `.ipynb` file and run the cells.
